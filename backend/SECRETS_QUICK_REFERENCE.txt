## 🚀 Quick Start (5 Steps)

### 1. Verify Secrets Loaded
```bash
python -c "from config import get_settings; s = get_settings(); s.validate()"
```
Expected: `All critical API keys validated and loaded`

### 2. Test App Import
```bash
python -c "from main import app; print('App ready')"
```
Expected: No errors

### 3. Check Connectivity (Optional)
```bash
python secrets_validator.py
```
Expected: Validation report for all providers

### 4. Start Development Server
```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
Expected: Startup shows all API keys loaded

### 5. Test Health Endpoint
```bash
curl http://localhost:8000/api/health
```
Expected: `{"status": "alive", ...}`

## 💡 Troubleshooting

| Issue | Solution |
|-------|----------|
| `ModuleNotFoundError: pythonjsonlogger` | `pip install python-json-logger` |
| Secrets not loading | Check .env file in `backend/` folder |
| Validation errors | Run `python SECRETS_INTEGRATION.py` for report |
| Service connectivity fails | Run `python secrets_validator.py` for details |
