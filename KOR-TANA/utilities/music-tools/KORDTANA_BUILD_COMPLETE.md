## What Kordtana Adds to Music Theory

### 1. Emotional Taxonomy

8 core emotions mapped to chord types:

- Clarity (maj, maj7) - ⟡
- Yearning (min9, min11) - ◈
- Movement (min7, dom7) - ⟠
- Suspension (sus2, sus4) - ⧖
- Tension (dom7, dim) - ↯
- Transcendence (maj9, maj7#11) - ∞
- Mystery (dim, m7b5) - ⌘
- Release (maj, maj6) - ⊙

### 2. Glyph System

Visual mnemonics that encode progressions:

```
⟡◈⟠⧖ = Tonic → Borrowed → Subdominant → Suspension
```

### 3. Ritual Architecture

- **Breath Maps**: Where to place lyrics/breath
- **Intentions**: The emotional purpose
- **Gestures**: Physical embodiment
- **Energy Curves**: Rising/falling/cyclical/plateau

### 4. Harmonic Intelligence

- **Function Analysis**: Tonic, subdominant, dominant roles
- **Voice Leading**: Common tone analysis
- **Modal Interchange**: Borrowed chord identification
- **Tension/Resolution**: Harmonic movement tracking
