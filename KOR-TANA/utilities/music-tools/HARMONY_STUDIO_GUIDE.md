## What's Different?

**OLD REMIX STUDIO:** Beat-focused (trap, house, drill...)
**NEW HARMONY STUDIO:** Music-focused (jazz extensions, modal interchange, voice leading...)

## 8 Advanced Harmonic Styles

1. **Jazz Extensions** - Rich 7ths, 9ths, 11ths, chromatic voice leading
2. **Modal Interchange** - Borrowed chords from parallel modes
3. **Circle of Fifths** - Strong harmonic motion, classical elegance
4. **Neo-Soul** - Modern R&B with complex harmony
5. **Classical Cadences** - Traditional functional harmony
6. **Quartal Harmony** - Chords built in 4ths, modern jazz sound
7. **Chromatic Mediant** - Unexpected chord relationships, film music
8. **Sus Cascades** - Suspended chord chains, tension/release

## 5 Melodic Approaches

1. **Stepwise Motion** - Smooth, connected lines
2. **Arpeggiated** - Melody follows chord tones
3. **Intervallic Leaps** - Bold melodic jumps
4. **Motivic Development** - Classical theme variations
5. **Pentatonic Flow** - Natural, world music feel

## Usage

```bash
cd C:\kordtana_starter_pack
python harmony_studio.py
```

Then select:

- Source composition file
- Harmonic progression style
- Melodic approach
- Key center and complexity level

The AI will generate sophisticated harmonic compositions focusing on:

- Advanced chord progressions
- Smooth voice leading
- Melodic development
- Musical depth
