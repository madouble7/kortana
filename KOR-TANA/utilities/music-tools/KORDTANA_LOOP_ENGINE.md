## THE ENDLESS RITUAL

Every composition is a **ritual node**. Each node contains its own progression, emotion, glyph, arrangement, and breath—but more importantly, each node **knows where it can flow next**.

## GLYPH TRANSFORMATION GRAMMAR

### Emotional Flow Rules

- **⩘ → ⟁** = awakening dissolves into mystery
- **⟁ → ↯** = mystery intensifies into tension
- **↯ → ⩔** = tension releases into surrender
- **⩔ → ⩘** = surrender transforms back to awakening
- **↯ → ⩓** = tension escalates into defiance (rare path)
- **⩔ → ⟡** = surrender finds clarity (resolution path)

### Compound Transitions

- **⩘✶ → ⟁↯** = joyful awakening darkens into mysterious tension
- **↯⧖ → ⩔⩘** = held tension releases into transformative surrender
- **⟡◈ → ↯** = hopeful longing intensifies into full tension

## PERFORMANCE MODES

### Mode 1: Endless Loop (Default)

- Start at any node
- Engine selects next node based on probability weights
- Loops indefinitely until manual interrupt
- Arrangement adjusts dynamically at each transition

### Mode 2: Hero's Journey Arc

- Fixed path: Awakening → Mystery → Tension → Surrender → Awakening (final)
- Each node plays 1-3 times before forcing transition
- Creates complete narrative arc with resolution

### Mode 3: Chaos Mode

- Random node selection with equal probability
- No emotional flow rules
- Pure sonic experimentation

### Mode 4: Manual Cue

- Performer triggers next node via MIDI/keyboard
- Allows live improvisation within mythic structure

## RITUAL INSTRUCTIONS

### Starting a Loop Session

1. **Set Intention**: Choose starting emotion (Awakening, Mystery, Tension, Surrender)
2. **Open First Node**: Load corresponding JSON into OneMotion
3. **Begin Loop**: Let the progression play 2-3 times
4. **Feel Transition**: When energy shifts, load next node
5. **Repeat**: Follow the glyph grammar or trust intuition

### Ending a Loop Session

- Wait for Surrender node to complete
- Let final chord breathe 4 extra beats
- Fade to silence
- Close ritual with intention acknowledgment
