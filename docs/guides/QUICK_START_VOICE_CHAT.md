## **That's It! But Here's What You Can Do:**

### **All Available Commands:**

```
status      → What are you doing?
dashboard   → Show me everything
tasks       → What tasks do you have?
metrics     → How are you performing?
health      → Are you healthy?
start       → Begin autonomous work
stop        → Stop working
check       → Check right now
help        → Show all commands
exit        → Quit
```
