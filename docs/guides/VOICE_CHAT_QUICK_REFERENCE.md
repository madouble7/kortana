# 🎤 Kor'tana Voice Chat - Quick Reference

## What's New

### Enhanced Conversation Features

- **Context Memory** - Remembers what you talked about
- **Follow-ups** - Say "Tell me more" about any topic
- **Varied Responses** - Different personality each time you chat
- **Smart Suggestions** - Helpful hints when unsure
- **Multi-turn Chats** - Deep dives into topics

---

## Commands by Category

### 💬 Ask About Status

```
"What's your status?"
"What are you doing?"
"Current status?"
"Tell me everything"
```

Follow up with: **"Tell me more"** for details

### 📊 Check Dashboard & Metrics

```
"Show dashboard"
"Dashboard overview"
"How am I doing?"
"Show metrics"
"Performance stats"
```

### ⚙️ Monitor System

```
"System health check"
"Are you okay?"
"System status"
"Everything okay?"
```

### 🎯 Control Monitoring

```
"Start monitoring"      → Begin autonomous work
"Stop monitoring"       → Pause operations
"Check now"            → Immediate system check
"Pause"                → Wait for next command
```

### 📋 Task Management

```
"What are you working on?"    → See current tasks
"List tasks"                  → Task inventory
"Approve"                     → Allow execution
"Retry"                       → Try again
```

### ❓ Get Help

```
"Help"                    → See capabilities
"What can you do?"       → Available features
"How does this work?"    → Explanation
"Tell me more"           → Deep dive on any topic
```

### 💬 Casual Chat

```
"Hello" / "Hi" / "Hey"   → Friendly greeting
"Thanks" / "Thank you"   → Gratitude
"How are you?"           → Check-in
"How do you feel?"       → Personal question
```

### 🚪 Exit

```
"Exit"  /  "Quit"  /  "Goodbye"  /  "Bye"
```

## Pro Tips

### 1. Use Follow-ups

```
You: "What are you working on?"
Kor'tana: [Lists tasks]
You: "Tell me more"
Kor'tana: [Detailed breakdown]
```

### 2. Ask Natural Questions

- Works best with conversational language
- Say "What's your status?" not just "Status"
- Use complete sentences when possible

### 3. Get Smart Suggestions

- If unclear, Kor'tana offers helpful hints
- Follow the suggestions to explore features
- Each conversation learns from previous inputs

### 4. Check Different Topics

- Dashboard for visual overview
- Metrics for performance details
- Health for system status
- Tasks for specific work items

## Troubleshooting

### Didn't Understand

- **Solution**: Speak clearly and slower
- **Try**: Rephrase the question
- **Hint**: Use simple, complete sentences

### Want More Details

- **Solution**: Say "Tell me more" after any response
- **Try**: "Explain that" or "More details"
- **Hint**: Follow-ups work on any topic

### Lost in Options

- **Solution**: Say "Help" to see all capabilities
- **Try**: Browse the categories above
- **Hint**: Kor'tana will suggest topics if unsure

---

## Voice Tips

✅ **DO:**

- Speak clearly and naturally
- Use complete questions
- Wait for the beep after speaking
- Take your time explaining

❌ **DON'T:**

- Mumble or speak too fast
- Use extremely technical jargon alone
- Interrupt during speech processing
- Speak too quietly
